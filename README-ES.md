## Sobre el concepto

- [Andrej Karpathy en X](https://x.com/karpathy/status/1886192184808149383) - "Hay un nuevo tipo de programación que llamo 'vibe coding', donde te dejas llevar por completo por las vibras, abrazas los exponenciales y te olvidas de que el código siquiera existe. (.) Estoy construyendo un proyecto o aplicación web, pero realmente no es programar; solo veo cosas, digo cosas, ejecuto cosas y copio y pego cosas, y la mayoría de las veces funciona".
- [Vibe coding - Wikipedia](https://en.wikipedia.org/wiki/Vibe_coding) - Artículo de Wikipedia que define el vibe coding y rastrea su origen.
- [El vibe coding pasó de moda - El New Stack](https://thenewstack.io/vibe-coding-is-passe/) - La evolución del concepto por parte de Karpathy hacia la "ingeniería agéntica".
- [automata/aicodeguide](https://github.com/automata/aicodeguide) - Una hoja de ruta para empezar a programar con IA.

## IDEs y Editores de código

- [Windsurf](https://windsurf.com/) - IDE agéntico (adquirido por Cognition, creadores de Devin) con Cascade para codificación en múltiples pasos y Tab/Supercomplete para autocompletado.
- 🔥 [Cursor](https://www.cursor.com/) - Editor de código de IA con agentes en la nube, integración con JetBrains y más de 30 plugins de socios como Atlassian, Datadog y GitLab.
- [Zed](https://zed.dev/) - El primer "IDE agéntico" construido en Rust con agentes de IA integrados y colaboración en tiempo real a 120fps.
- [Amazon Kiro](https://kiro.dev) - El IDE de IA para pasar del prototipo a la producción, con desarrollo guiado por especificaciones e integraciones con AWS.
- [Google Antigravity](https://antigravity.google/) - Plataforma de desarrollo agéntico de Google con vista de Administrador para orquestar múltiples agentes en paralelo. Gratuito y multiplataforma.
- [Orchids](https://www.orchids.app/) - El IDE de Vibe Coding que puede construir, observar y escuchar a la par de un desarrollador humano.
- [Trae IDE](https://www.trae.ai/) - IDE de IA gratuito de ByteDance con Modo Constructor, acceso gratuito a GPT-4o, Claude Sonnet y DeepSeek R1.
- [Devin](https://devin.ai/) - Ingeniero de software de IA autónomo de Cognition con su propio IDE, terminal, navegador y entorno de pruebas en la nube (sandbox).

## Aplicaciones locales

- [CCHub](https://github.com/Moresl/cchub) - Aplicación de escritorio para gestionar el ecosistema de Claude Code: mercado de servidores MCP, cambio de perfiles de configuración, plantillas de flujo de trabajo, auditoría de seguridad y piloto automático. Construida con Tauri + React + Rust.
- 🔥 [Dyad](https://www.dyad.sh/) - Constructor de aplicaciones de IA gratuito, local y de código abierto. Independiente del modelo, es compatible con modelos en la nube y locales a través de Ollama.
- [bolt.diy](https://github.com/stackblitz-labs/bolt.diy) - Versión de código abierto de Bolt.new con aplicaciones de escritorio Electron, soporte para más de 19 proveedores de IA y modelos locales mediante Ollama.
- [Superset](https://github.com/superset-sh/superset) - Aplicación de escritorio para orquestar múltiples agentes de codificación de IA en paralelo (Claude Code, Codex, etc.) con aislamiento de árbol de trabajo de Git (worktree).
- [Parallel Code](https://github.com/johannesjo/parallel-code) - Aplicación de escritorio para ejecutar simultáneamente múltiples agentes de codificación de IA (Claude Code, Codex CLI, Gemini CLI) en árboles de trabajo de git aislados.

- [CCPM (Claude Code PM)](https://github.com/automazeio/ccpm) - Gestión de proyectos para Claude Code utilizando GitHub Issues y árboles de trabajo de Git para la ejecución de agentes en paralelo.
